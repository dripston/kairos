reference_check.py, outputs/). Every number in every output is computed from one run's

## Where to put this folder

Unzip `kairos-varun` **inside** the folder that holds Ojas's packs (`kairos-policy/`, next to
`K01-decision-policy/`, `K21-propensity-intensity/`, `K10-inbound-conversation/`). The engine then reads
Ojas's files directly, so any policy update by him flows in. If his folders aren't found it uses the
identical bundled copies in `kairos_engine/policy_bundled/` and says so in the run manifest.

## Run it (Mac: use `python3` and `pip3`)

```bash
pip3 install numpy pandas
cd kairos-varun
python3 run_all.py            # fresh 50K run + all 42 tests, about 4-6 minutes
python3 run_all.py --checks   # tests only, on the latest run
```

Each task can also be checked alone: `cd K15-safety-load-replay && python3 reference_check.py`.
Results are saved in each folder's `outputs/test_results.json`.
